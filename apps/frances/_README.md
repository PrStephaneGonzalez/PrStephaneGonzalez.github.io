# Francés oral — version publiée

Fichiers **générés** (`npm run build` du projet source « frances-oral », React + Vite) : ne pas les modifier à la main.
Pour mettre à jour : dans le projet source, `npm run check && npm run build`, puis remplacer le contenu de ce dossier par `dist/`.

- Version : 0.1.0 (appli sœur d'« Espagnol oral » pour hispanophones du Mexique qui apprennent le français ; 1 500 mots, 26 leçons, 9 situations de conversation, 1 120 phrases utiles ; contenu en brouillon, non relu)
- Sauvegarde en ligne facultative : table `frances_profils` et fonctions `frances_*` du projet Supabase partagé.
