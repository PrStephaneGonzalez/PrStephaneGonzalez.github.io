# Espagnol oral — version publiée

Fichiers **générés** (`npm run build` du projet source « espagnol-oral », React + Vite) : ne pas les modifier à la main.
Pour mettre à jour : dans le projet source, `npm run check && npm run build`, puis remplacer le contenu de ce dossier par `dist/`.

- Version : 0.6.0 (lecture automatique français puis espagnol, sons de réussite, conjugaison complète au présent ; 1 500 mots illustrés, 23 leçons, 9 situations de conversation, 1 062 phrases utiles ; profils prénom + code à 4 chiffres ; contenu en brouillon, non relu)
- Sauvegarde en ligne facultative : table `espagnol_profils` et fonctions `espagnol_*` du projet Supabase partagé (même principe que INFLUENCE et le Fil d'Or).
